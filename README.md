# Amulya Murahari — Software Engineering Portfolio

A polished, responsive portfolio showcasing my software engineering experience, projects, and technical skills.

**Live site:** [amulyamurahari.github.io](https://amulyamurahari.github.io)

## Built With

- Next.js and React
- TypeScript
- Tailwind CSS
- Vite and vinext

## Local Development

Node.js 22.13 or newer is recommended.

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

- Home
- About
- Experience

- Contact

The portfolio content is based on my resume and professional materials.
